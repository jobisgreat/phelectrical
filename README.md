# PH Electric website

Static site for Piquette & Howard Electric Service. Plain HTML/CSS/JS, no build step.

- `index.html`: homepage
- seven capability pages (`*.html`)
- `styles.css`, `site.js`: shared styles and the RFQ form script
- `img/hero.webp`: homepage header photo

Yellow "TO FILL IN" and "UNVERIFIED" markers are content still waiting on a verified source (RFQ email, form endpoint, design-build and telecom detail).
